# CareCase - Digital Patient Case Management System

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. For easier development, install the VS Code **Live Server** extension and choose **Open with Live Server**.
4. Demo login:
   - Email: `doctor@carecase.demo`
   - Password: `1234`

## Included modules
- Login screen
- Dashboard
- Patient registration
- Patient directory and search
- Case records
- Browser LocalStorage persistence
- JSON export
- Emergency triage support checklist
- Browser voice-based case taking
- Responsive layout
- Project overview

## Important
This is a college-project prototype, not a production healthcare application. It does not provide medical diagnosis. A real deployment needs a secure backend/database, proper authentication and authorization, encryption, audit logs, backups, privacy controls, clinical validation, and compliance with applicable laws and institutional requirements.
